### About Me

Hi, I'm Rebecca, I'm a Software Engineer, working for a Software Development Agency specialising in bespoke web applications. I first started programming with an industry led bootcamp called Northcoders, and have loved learning, developing and building applications ever since.

I have experience working with different programming languages and frameworks. I have experience both providing support to legacy applications, and designing new features, from speaking to customers, understanding their technical requirements and then building the final product for them.

I have loved developing my problem solving skills, and working at an agency has equipped me with the confidence in my ability to learn new skills in a short period of time. I’m passionate about continuing to develop my skills, tackling new challenges, and building applications that solve real-world problems.
